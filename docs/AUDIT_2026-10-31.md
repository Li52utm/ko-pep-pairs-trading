# Independent audit: KO/PEP pairs-trading case study

Date: 31 October 2026. Scope: every module in `src/`, the seven chapters, the tests, the
documents and the deployment path. Read-only: no project file was changed except this report.
Data as of the committed snapshot (last close 30 October 2026).

## 1. Summary

1. **The core numbers are right.** An independent re-implementation (no `src/` imports) reproduces the
   default backtest, the CHF carry, put-call parity, the luck percentile and the option net cost exactly.
2. **No look-ahead found.** Signals, research selection and walk-forward selection use past data only.
3. **One crash (High):** chapter VII fails whenever the protective call has a zero bid/ask (weekend quotes).
4. **One deployment risk (High):** on a server where live data works, chapters computed live and chapters
   read from saved results can show different data dates, and the numbers would silently disagree.
5. **Several Medium/Low issues:** FX-driven date gaps change the KO/PEP sample, network-dependent tests,
   unconditional conclusions in a few sentences, typed-in constants, a stale test count in the README.

## 3. Verified correct

| What | How |
|---|---|
| Default KO/PEP backtest (rolling 60-day OLS on t−60..t−1, entry band, cooldown, t+1 execution, 1:\|β\| sizing locked at entry, 5 bps per leg per side, 0.5% borrow) | Independent loop implementation from the written rules: identical trade count, win rate, stops, total P&L (to $0.000005) and Sharpe (to 1e-10). Zero entries beyond the stop. |
| No look-ahead in signals | Independent rolling estimates use only t−60..t−1 and reproduce the project's z-scores (last z 2.050419 both). No `shift(-…)` anywhere; no future-indexed reads inside time loops. |
| Adjusted closes | Yahoo's back-adjustment rescales all prices before a future dividend by one factor, a constant shift in log price that alpha absorbs, so z-scores are unaffected. |
| Research selection uses train data only | `select_params` reads only `train_*` columns; the test Sharpe of the chosen setting is unchanged by test data (existing test `test_selection_ignores_test_period`). |
| Walk-forward selection uses formation data only | Code: `prices.iloc[start - formation : start]`; existing test scrambles later prices and the first window's selection is identical. |
| Rates and FX timing | Carry accrues on day t−1's rates (`usd_rate[t-1]`, `chf_rate[t-1]`); the Swiss monthly series is shifted one month; FX staleness is documented. |
| CHF carry-only total and the SNB day | Independent recursion from the CLAUDE.md formulas: CHF 18,720.44 and −CHF 165,146.78 on 2015-01-16, both exact matches; also the worst day overall. |
| Put-call parity, implied forward, implied borrow, American bounds | Independent cleaning and formulas from the snapshot: same 25 usable quotes, 9 paired strikes, median implied forward $94.3770, implied borrow −0.261%.
